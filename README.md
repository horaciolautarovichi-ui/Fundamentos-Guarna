# 🐍 FIUBA - Algoritmos y Programación I - Fundamentos De Prodramacion

Repositorio con resoluciones de ejercicios de parciales, prácticas con `doctest` y guía de referencia sobre métodos y funciones de Python según el programa de la materia.

---

## 📌 Contenido del Repositorio

* **`parciales_resueltos/`**: Modelos y finales/parciales pasados resueltos paso a paso en Python.
* **`apuntes/`**: Resumen de métodos de cadenas, listas, diccionarios y funciones incorporadas.
* **`pruebas_doctest/`**: Ejercicios de validación y lógica testeados automáticamente con la librería `doctest`.
